# StudyHub — Organizador Escolar

Aplicación web ligera y elegante pensada para estudiantes de preparatoria. Permite gestionar tareas, materias con promedios ponderados por rubro, horario semanal, temporizador Pomodoro y sincronización en la nube con Supabase.

## Funciones principales

- **Tareas y Exámenes**: organización por materia, tipo, prioridad y etiquetas de urgencia (`Para hoy`, `Mañana`, `Vencida`).
- **Materias y Promedio Ponderado**: cada alumno define el porcentaje de cada rubro (Examen, Actividades, Proyecto, Participación o rubros personalizados) y obtiene su promedio en tiempo real.
- **Horario Semanal**: vista ordenada por día y hora con salón o enlace.
- **Modo Enfoque (Pomodoro)**: temporizador con anillo de progreso circular y contador de sesiones.
- **Sincronización con Supabase**: funciona sin cuenta en `localStorage` y permite iniciar sesión o registrarse para respaldar y sincronizar en la nube.

## Uso local

Abre `index.html` directamente en cualquier navegador moderno.
